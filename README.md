# Estudio Raíz

Sitio de **Estudio Raíz**, la consultora que crea, protege y hace crecer marcas: registro en el INPI, branding, marketing digital y desarrollo web.

**Sitio:** https://estudio-raiz.vercel.app

- Landing con búsqueda de marcas en la base pública del INPI (`web/api/marcas.js`, función serverless).
- Formulario de contacto que abre WhatsApp con la consulta escrita (no guarda datos).
- Sección de **trabajos realizados** con las webs y apps desarrolladas.
- Políticas de privacidad y términos que aplican a todos los sitios desarrollados por Estudio Raíz.

Todo lo publicable vive en `web/` (ver [web/README.md](web/README.md)). HTML, CSS y JavaScript sin dependencias.
